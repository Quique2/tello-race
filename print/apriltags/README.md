# AprilTag plates for 3D printing (tag36h11, IDs 1-4)

Generated by `genera_apriltags.py` (run with `uv run genera_apriltags.py`; it installs its own dependencies), the same
recipe as the QR pieces in Prints-MIND: a flush two-colour inlay, base in cream/white and the dark modules as a 0.4 mm
colour layer, plate 200 x 200 x 1.6 mm.

Per ID: `<name>.3mf` (two extruders, opens in Bambu Studio / OrcaSlicer with the parts already assigned),
`<name>_base.stl` + `<name>_tag.stl` (same two parts for any slicer, import both and assign colours), and
`<name>_paper_300dpi.png` to print on paper at 100 % as a fallback.

Verified: each rendered face decodes with OpenCV's tag36h11 dictionary, and a synthetic video of the four plates fed to
`tello_race replay` was recognised by the real detector as IDs 1, 2, 3, 4 in order.

Rules for the detector:
* The black square is 160 mm = `tag.size_m 0.16` in `config/default.ini`. If you print smaller (`--black 120`), set
  `tag.size_m` to match, otherwise distances to the tag are wrong.
* Keep the white quiet zone (the outer 20 mm) clean: no text, no tape, no marker. Label the back if needed.
* Dark filament: black is best, navy decodes fine (that is what the self-test renders). Matte finish; a glossy plate
  reflects the ceiling lights and blinds the camera.
* Print flat, 100 % scale, first layer face down (the plate is symmetric so either side works). Competition meaning:
  ID1 forward, ID2 left, ID3 right, ID4 finish.
